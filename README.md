# deqcert

**A dequantization certifier for parameterised quantum circuit encoders.**

Hand it a circuit. It tells you whether that circuit's readout can be reproduced
by a comparably cheap classical model — and if it can, it hands you the model.

Whether a parameterised quantum circuit used as a feature encoder computes
anything beyond the reach of a comparably cheap classical model is, at deployable
sizes, a decidable question. It is settled by two quantities: the dimension of the
circuit's **dynamical Lie algebra**, and the **frequency support** generated by its
data encoding. The theory establishing this is well developed. What it does not
supply is the verdict for *your* circuit, which until now has meant a bespoke
derivation. That is the gap this tool closes.

## Install

```bash
pip install deqcert                # core, needs only numpy
pip install "deqcert[qiskit]"      # adds the QuantumCircuit importer
```

Or from a clone:

```bash
pip install -e ".[qiskit,test]"
```

## Use it

```bash
deqcert hqz_base       # certify a built-in encoder
deqcert --list         # what is built in
deqcert --selftest     # internal validation phases
```

```
========================================================================
  DEQUANTIZATION CERTIFICATE: hqz_base  (n = 4 qubits)
========================================================================
  VERDICT:  DEQUANTIZABLE (bounded function class)
  surrogate basis size B = 8   certified residual = 1.78e-15
  cost: classical O(8) vs statevector O(16)
  explicit surrogate [Z0]:  +0.3915 cos(1c0)  +0.6085 cos(1c0)*cos(1c1)
                            -0.4653 sin(1c0)  +0.4653 sin(1c0)*cos(1c1)
```

That last line is the point. The circuit is not merely *declared* reproducible —
the classical function that reproduces it is printed, and it was fitted from
circuit evaluations alone and accepted only once it agreed to round-off.

From Python:

```python
from deqcert import certify, print_report, EXAMPLES

report = certify(EXAMPLES["zz_feature_map"]())
print_report(report)

print(report.verdict)              # the decision
print(report.surrogate_residual)   # how exactly the surrogate matched
print(report.cost)                 # classical O(B) vs statevector O(2^n)
```

## The three verdicts

| verdict | meaning |
|---|---|
| **dequantizable** | An explicit classical surrogate is returned with its evaluation cost. |
| **frequency escape** | Data is re-uploaded at a trainable scale, so the readout leaves any fixed finite basis. A *deployed* instance at fixed scales is still surrogatable on its realised frequency set. |
| **algebra escape** | The readout exhausts the space a bounded algebra allows. An entanglement reading is attached to indicate whether that escape is genuinely costly or would yield to a tensor-network method. |

**An escape verdict is not a claim of quantum advantage.** It says the circuit is
not reproducible by the surrogate *this tool* constructs. Methods outside its
basis — tensor networks, Pauli propagation — may well reproduce a circuit deqcert
declines to certify. The asymmetry is deliberate: a *dequantizable* verdict is
constructive and backed by a round-off residual; an escape verdict is an admission
of the method's boundary.

## Your own circuit

Describe it as an ordered gate list with Pauli-Z readouts:

```python
from deqcert import EncoderSpec, certify, print_report

spec = EncoderSpec(
    name="my_encoder",
    n_qubits=2,
    n_features=2,
    gates=[
        ("rot",  "X", 0, ("data", 0, 1.0)),      # R_X(x0) on qubit 0
        ("rot",  "X", 1, ("data", 1, 1.0)),      # R_X(x1) on qubit 1
        ("crot", "Z", 1, 0, ("param", "alpha")), # CRZ(alpha), control 1, target 0
        ("crot", "X", 1, 0, ("param", "beta")),  # CRX(beta)
    ],
    readouts=["Z0"],
)
print_report(certify(spec))
```

Angle sources are `("data", feature, scale)`, `("param", name)` or
`("fixed", value)`. Declaring a *trainable* scale on a data angle, as
`("data", 0, ("param", "lam"))`, is how data re-uploading is expressed — and it is
what triggers a frequency escape.

Or import from Qiskit, naming the parameters that carry data:

```python
from deqcert import from_qiskit, certify, print_report

spec = from_qiskit(qc, data_params=[x0, x1], readouts=["Z0"])
print_report(certify(spec))
```

## What it measures

- **Dynamical Lie algebra.** Closed over the generators of the *full* gate set,
  fixed entanglers included, up to a ceiling. This matters: counting only the
  parametrised generators of a hardware-efficient ansatz gives a small algebra and
  the wrong answer, because fixed CNOTs lie outside `exp(g)`.
- **Encoding-frequency support.** Bounded or unbounded, per feature.
- **Readout effective dimension.** SVD rank over random parameters and inputs.
- **The surrogate.** Products of `1`, `cos` and `sin` of each distinct encoding
  channel, with harmonic order raised until the fit stops improving, and
  cross-channel terms included for product angles. Coefficients by least squares
  from slightly more circuit evaluations than basis terms.
- **Mean bipartite entanglement**, as a tractability heuristic on algebra escapes.

The decisive quantity is the function exposed at the measurement, **not** the size
of the algebra behind it. A large algebra is reported as context, never as a
verdict — the built-in `hqz_cross` fills the algebra ceiling and is still
reproduced exactly by a sixteen-term model.

## Limitations

- Covers encodings where **data enters as gate angles**: plain, weighted,
  re-uploaded, and product feature maps. Amplitude and basis encodings do not
  produce a trigonometric function of the inputs and are reported as outside the
  surrogate's reach, not certified either way.
- The surrogate basis grows as (encoding channels) × (harmonic order), of order
  `n²` for pairwise product maps, so it exhausts its budget at moderate width.
  Beyond that the tool reports an escape *by cost*, not by structure.
- The algebra closure and the effective-dimension estimate are both **capped**; a
  value reported at the ceiling means only "at least this large".
- The entanglement figure is a heuristic, not a hardness proof.
- CPU only.

## Built-in encoders

`hqz_base`, `hqz_cross`, `reenc_pair`, `vqc_facedet`, `zz_feature_map`,
`minimal_qcnn`, `minimal_qcnn_ae` — run `deqcert --list`.

`zz_feature_map` is the Havlíček *et al.* ZZ feature map, which deqcert certifies
as classically reproducible despite a dynamical Lie algebra of dimension 63,
returning a 224-term surrogate accurate to 8.6 × 10⁻¹⁵.

## Tests

```bash
pytest                  # everything, ~100 s
pytest -m "not slow"    # the fast subset, ~1 s
```

The suite asserts the four verdicts reported in the paper. All but one run in
under a second; certifying the 8-qubit `vqc_facedet` ansatz takes around 100
seconds, since closing its dynamical Lie algebra is genuinely expensive.
